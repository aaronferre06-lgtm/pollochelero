# El Pollo Chelero

- **Pizarra del menú** (armar la imagen del menú del día para WhatsApp): https://aaronferre06-lgtm.github.io/pollochelero/
- **Pedidos por QR** (el cliente elige y el pedido llega por WhatsApp): https://aaronferre06-lgtm.github.io/pollochelero/pedidos.html
- **Carteles QR para imprimir**: https://aaronferre06-lgtm.github.io/pollochelero/pedidos.html#carteles

La carta de pedidos está en `carta.json` (sección, plato, precio y, si se quiere, el link de una foto).
Si un plato no tiene foto, la página la busca sola en Wikimedia Commons por el nombre.
